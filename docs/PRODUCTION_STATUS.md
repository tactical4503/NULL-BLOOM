# Production status

## Implemented
- Repository foundation
- Browser entry point
- Fixed-step combat loop
- Fighter state machine
- Movement/jump/fall
- Attack startup/active/recovery data
- Hitbox/hurtbox collision
- Damage, hitstun, hitstop and knockback
- CPU opponent
- Round tracking
- Modular fighter recipe creator
- Local save/import/export for creator recipes
- Eight-character roster manifest and distinct authored visual specifications

## Still required for the full target
- Authored production sprite/animation art for every roster member
- Complete per-character move sets
- Sound/music
- Character select / versus presentation
- Full training diagnostics and hitbox overlays
- Persistence beyond browser-local creator recipes
- Mobile/controller input
- Automated browser test pass and production asset validation

The repository should not be described as a finished commercial game yet.
